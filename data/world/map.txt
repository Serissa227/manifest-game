// 旧世界（大致在 x < 240、y < 120）环抱内海“维斯塔海”：西陆埃斯佩兰（地中海式丘陵与溺谷海岸）、北境诺德海姆（峡湾与针叶林）、
// 东陆范德兰（低地、河口与堰洲岛）、南陆卡迪尔（沙漠、大河三角洲与绿洲），内海中部是马纳瓦群岛（火山岛弧与沉没的阿尔坎尼斯破火山口）。
// 内海东南的海峡“巨人之门”（约 x 240–262、y 100–107）是唯一的出海口，通往外洋“晨星洋”；
// 东部与东南是新大陆“阿斯特里亚”（北部峡湾、晨光湾、长鼻岬、银雾湾、翡翠湾、日痕荒原、赤礁海岸），南部是瑶华帝国的群岛。
// 一格约三十公里（y = 0 约北纬 62°，y = 170 约北纬 10°）；埃斯佩兰以西是外海（与图内其他海域不相连），北缘、东缘与西南角是延伸到图外的陆地。
